## Cron Jobs Configuration

The following cron jobs are configured in `vercel.json`:

### 1. Token Refresh (Every 6 hours)
- **Path:** `/api/cron/refresh-accountpe-token`
- **Schedule:** `0 */6 * * *` (Every 6 hours)
- **Purpose:** Refreshes the AccountPe JWT token
- **Action:** Calls AccountPe auth API and stores token in database

### 2. Payment Verification (Every 10 minutes)
- **Path:** `/api/cron/verify-instant-payments`
- **Schedule:** `*/10 * * * *` (Every 10 minutes)
- **Purpose:** Checks pending payment statuses
- **Action:** Updates payment status and credits user balance

### 3. Order Sync (Every 15 minutes)
- **Path:** `/api/cron/sync-orders`
- **Schedule:** `*/15 * * * *` (Every 15 minutes)
- **Purpose:** Syncs order statuses with API providers

## Database Setup

Ensure your Supabase database has the following:

### system_settings table
Must have an `accountpe_token` column:
```sql
ALTER TABLE system_settings ADD COLUMN IF NOT EXISTS accountpe_token TEXT;
```

### instant_payments table
Must have these columns:
- `id` (UUID)
- `user_id` (UUID)
- `amount` (NUMERIC)
- `status` (TEXT) - Values: 'pending', 'completed', 'failed'
- `external_transaction_id` (TEXT) - AccountPe transaction ID
- `payment_method` (TEXT) - 'instant_xaf'
- `completed_at` (TIMESTAMP)
- `failed_at` (TIMESTAMP)

## Payment Flow

1. **User initiates payment:**
   - User fills amount in instant payment form
   - System creates transaction with status='pending'
   - Calls AccountPe API to create payment link
   - Redirects user to payment link

2. **User completes payment:**
   - User pays on AccountPe platform
   - AccountPe processes payment

3. **Cron job verifies payment:**
   - Every 10 minutes, cron checks pending payments
   - Calls AccountPe status API
   - If status=1 (success), credits user balance
   - If status=2/5/6 (failed), marks as failed

4. **User sees updated balance:**
   - Transaction appears in history
   - Balance reflects the payment

## Troubleshooting

### Token Refresh Fails
- Check ACCOUNTPE_EMAIL and ACCOUNTPE_PASSWORD are correct
- Verify AccountPe API is accessible
- Check Vercel logs for error details

### Payment Verification Not Working
- Ensure token is being refreshed successfully
- Check that instant_payments table has pending records
- Verify external_transaction_id is stored correctly
- Check AccountPe API response format

### Cron Jobs Not Running
- Verify CRON_SECRET is set in environment variables
- Check vercel.json has correct paths
- Ensure project is deployed (crons only run in production)

## Security Notes

1. **Never commit credentials to git**
   - Keep environment variables in Vercel only
   - Use `.env.local` for local development

2. **CRON_SECRET protection**
   - Generate a strong random secret
   - Use `openssl rand -base64 32` to generate one

3. **API rate limits**
   - AccountPe may have rate limits
   - Monitor and adjust cron frequency if needed
