# 🚀 Deploy Karne Ka Tarika - How to Deploy

## हिंदी में (In Hindi)

### आपको क्या करना है (What You Need to Do)

**सबसे आसान तरीका (Easiest Way):**

1. **GitHub खोलें:**
   - यहाँ जाएं: https://github.com/keshavsainit12/nextwave-smm-panel
   - "Pull requests" पर क्लिक करें
   - "copilot/fix-admin-panel-price-update-issue" वाला PR खोजें

2. **Merge करें:**
   - हरा "Merge pull request" बटन दबाएं
   - "Confirm merge" पर क्लिक करें

3. **बस हो गया!**
   - Vercel automatically deploy कर देगा
   - 2-3 मिनट में live हो जाएगा

### या Script चलाएं (Or Run Script)

```bash
./deploy.sh
```

फिर menu से option चुनें!

---

## English

### What You Need to Do

**Easiest Method:**

1. **Open GitHub:**
   - Go to: https://github.com/keshavsainit12/nextwave-smm-panel
   - Click "Pull requests"
   - Find PR: "copilot/fix-admin-panel-price-update-issue"

2. **Merge:**
   - Click green "Merge pull request" button
   - Click "Confirm merge"

3. **Done!**
   - Vercel will auto-deploy
   - Live in 2-3 minutes

### Or Run Script

```bash
./deploy.sh
```

Then select option from menu!
