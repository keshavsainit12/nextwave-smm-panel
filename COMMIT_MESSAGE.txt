fix: Resolve instant payment data model mismatch and webhook processing

## Description
Fixed critical issues preventing instant XAF payments from being credited to users:

1. **Data Model Mismatch**: Payment creation used `transactions` table but verification looked in `instant_payments` table, causing payments to never be found or processed.

2. **Transaction ID Generation**: Added explicit transaction ID generation to ensure transactions can be reliably found by webhooks.

3. **Webhook Transaction Lookup**: Reversed lookup order to prioritize direct ID match (which is always set) over external payment_id (which is set later).

4. **Cron Job Verification**: Simplified cron job to monitor pending payments instead of making AccountPe API calls, which were failing due to missing transaction IDs.

## Changes Made
- app/actions/instant-payments.ts: Added explicit transaction ID generation
- app/api/webhooks/instant-payment/route.ts: Reordered transaction lookup for reliability
- app/api/cron/verify-instant-payments/route.ts: Changed to query transactions table and simplified logic

## Impact

- ✅ Webhook can reliably find and update transactions
